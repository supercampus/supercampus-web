# Counselling & Mental Wellness Workflow

## Overview

The Counselling & Mental Wellness module provides a confidential, structured system for students to request counselling, schedule appointments, manage cases, participate in wellness programs, and receive emergency mental health support.

## Individual Workflows

### 1. Counselling Requests

| Step | Action | Details |
|------|--------|---------|
| 1 | **Student Login Portal** | Authenticate into the counselling system |
| 2 | **Submit Counselling Request** | Initiate a new counselling request |
| 3 | **Select Counselling Category** | Choose: Academic / Personal / Mental Health |
| 4 | **Provide Concern / Description** | Describe the issue in detail |
| 5 | **Choose Confidentiality Preference** | Set privacy level for the request |
| 6 | **Submit Request for Review** | Send to counselling team |
| 7 | **Assign Counsellor** | Auto-assigned or manually assigned |
| 8 | **Appointment Scheduling** | Book a session with the assigned counsellor |

### 3. Case Management

| Step | Action | Details |
|------|--------|---------|
| 1 | **Counselling Session Completed** | Session ends and notes are recorded |
| 2 | **Create / Update Student Case** | Open or update the student's case file |
| 3 | **Record Counselling Notes** | Document session insights and observations |
| 4 | **Attach Documents (Optional)** | Upload relevant documents |
| 5 | **Assess Severity / Risk Level** | Evaluate the student's condition |
| 6 | **Low Risk** → Close Case | Issue resolved, no further action needed |
| 7 | **Moderate Risk** → Follow-up Plan | Schedule additional sessions |
| 8 | **High Risk** → Emergency Escalation | Activate emergency support protocol |
| 9 | **Case Status Updated** | Log the final disposition |

### 5. Emergency Support

| Step | Action | Details |
|------|--------|---------|
| 1 | **Student / Staff Raises Emergency** | Emergency request is submitted |
| 2 | **Emergency Request Received** | System captures the alert |
| 3 | **Assess Emergency Severity** | Evaluate the level of urgency |
| 4 | **Low** → Notify Counsellor | Standard counsellor notification |
| 5 | **Moderate** → Notify Emergency Counsellor | Priority alert to senior counsellor |
| 6 | **Critical** → Activate Emergency Response Team | Full emergency protocol |
| 7 | **Parent / Guardian Notification** | Inform family if required |
| 8 | **Medical / Security Support** | Coordinate with relevant departments |
| 9 | **Incident Documentation** | Record all emergency details |
| 10 | **Case Management Updated** | Link to student's ongoing case |
| 11 | **Follow-up Counselling Plan** | Schedule post-emergency support |

## Key Features Summary

| Feature | Description |
|---------|-------------|
| **Counselling Requests** | Students can submit requests with category and confidentiality preferences |
| **Appointment Booking** | Self-service scheduling with counsellor availability |
| **Case Management** | Structured tracking with severity-based disposition |
| **Wellness Programs** | Workshops, seminars, and awareness campaigns with participation tracking |
| **Emergency Support** | Tiered response system (Low / Moderate / Critical) |
| **AI Wellness Insights** | Engagement analytics and trend detection |
| **Notifications** | Alerts for students, counsellors, and emergency contacts |
| **Reports & Analytics** | Comprehensive reporting on counselling activities and outcomes |
