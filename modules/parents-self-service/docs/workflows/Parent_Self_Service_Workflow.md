# Parent Self Service Workflow

## Overview

The Parent Self Service module gives parents secure access to their child's academic and administrative information — attendance, marks, fees, homework, timetable, leave requests, and institutional communications — with real-time alerts and a social wall for announcements.

## Individual Workflows

### 1. Parent Attendance

| Step | Action | Details |
|------|--------|---------|
| 1 | **Parent Login** | Authenticate into portal |
| 2 | **Select Student** | Choose child profile |
| 3 | **View Attendance Summary** | Overall attendance overview |
| 4 | **Apply Filters (Date • Subject)** | Narrow down records |
| 5 | **View Daily / Monthly Records** | Detailed attendance log |
| 6 | **Attendance Percentage Display** | Visual percentage indicator |
| 7 | **Attendance Shortage (If Any)** | Alert if below threshold |
| 8 | **Download Attendance Report** | Export for records |

### 9. Absence Alert

| Step | Action | Details |
|------|--------|---------|
| 1 | **Student Marked Absent Today** | Attendance processed |
| 2 | **Attendance Processing Completed** | System check |
| 3 | **Verify Leave Approval** | Check for approved leave |
| 4 | **Leave Approved** → No Alert Generated | Skip notification |
| 5 | **Leave Not Found** → Generate Absence Alert | Create alert |
| 6 | **Notify Parent via App / SMS / Email** | Multi-channel alert |
| 7 | **Alert History Updated** | Log notification |

## Key Features Summary

| Feature | Description |
|---------|-------------|
| **Attendance** | Daily/monthly records, percentage display, shortage alerts, downloadable reports |
| **Marks** | Subject-wise marks, grades, ranks, performance charts, AI insights |
| **Fees** | Paid/pending/fine breakdown, online payment, receipts, and history |
| **Homework** | Subject-wise assignments, due dates, submission status, teacher instructions |
| **Communication** | Two-way messaging with teachers and administration, announcement reading |
| **Leave Requests** | Parent-initiated leave with document upload and approval tracking |
| **Timetable** | Daily/weekly class schedules with faculty and room details |
| **Profile** | Contact updates, communication preferences, password management |
| **Absence Alerts** | Automatic alerts when student is absent without approved leave |
| **Parent Wall** | Social feed for announcements, events, circulars, and achievements |
| **Reports** | Activity history and downloadable reports |
