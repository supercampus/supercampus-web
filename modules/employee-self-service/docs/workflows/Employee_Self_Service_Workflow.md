# Employee Self Service Workflow

## Overview

The Employee Self Service module empowers faculty and staff to manage their profiles, academic responsibilities, administrative tasks, research activities, and performance metrics through a unified self-service portal.

## Individual Workflows

### 1. Profile

| Step | Action | Details |
|------|--------|---------|
| 1 | **Employee Login** | Authenticate into portal |
| 2 | **View Employee Profile** | Personal and professional details |
| 3 | **Personal Info** • **Contact Details** • **Qualification** | Sections |
| 4 | **Update Editable Details** | Modify allowed fields |
| 5 | **Upload Documents (Optional)** | Attach certificates |
| 6 | **Submit for Verification** | Route for approval |
| 7 | **Approved** → Profile Updated | Changes saved |
| 8 | **Needs Revision** → Notify Employee | Request corrections |

## Key Features Summary

| Feature | Description |
|---------|-------------|
| **Profile** | Personal, contact, and qualification management with verification |
| **Workload** | Teaching, administrative, and research load with AI distribution |
| **Performance** | Multi-dimensional KPIs with student feedback integration |
| **Research** | Project creation, tracking, and status updates |
| **Publications** | DOI-linked publication repository with export |
| **Timetable** | Weekly schedule with lecture, practical, and tutorial details |
| **Attendance** | Class-wise student attendance marking and validation |
| **Payroll Inputs** | Extra hours, allowances, and deductions with approval |
| **Research Tracking** | Milestone-based project progress with document uploads |
| **Leave** | Multi-type leave application with balance tracking |
| **Communication** | Hub-based messaging with delivery and read receipts |
| **Class Notes** | Lecture notes and resource publishing to students |
| **Wall** | Faculty social feed for announcements and collaboration |
| **AI Insights** | Performance and workload analytics |
